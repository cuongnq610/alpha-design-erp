# Cài ALPHA DESIGN ERP trên iPhone/iPad

1. Mở địa chỉ ERP production bằng **Safari**.
2. Nhấn nút **Chia sẻ**.
3. Chọn **Thêm vào Màn hình chính**.
4. Giữ tên `ALPHA ERP` và nhấn **Thêm**.
5. Mở biểu tượng ALPHA ERP trên màn hình chính và đăng nhập.

Ứng dụng PWA dùng cùng dữ liệu Cloud với máy tính. Khi mất mạng, thay đổi được xếp hàng và đồng bộ lại sau khi kết nối trở lại.

Để phát hành qua App Store dưới dạng ứng dụng native, cần Apple Developer Account, máy Mac/Xcode và quy trình ký ứng dụng. Thư mục `mobile-wrapper` là cấu hình khởi đầu cho Capacitor.
